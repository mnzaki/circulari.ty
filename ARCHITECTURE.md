# Architecture

## Namedrops

[CWTCH](https://cwtch.im) tech for all first contact and exchange of identity information.

ID info is [KERI](https://keri.one) KELs.

P2P data transfer over websockets.

Communal data storage over one of
- [IPFS](https://ipfs.io)
- [DAT project](https://datproject.org)

Prexisting server networks leveraged to host data compatible with their own
native data:
- irc
- mastodon
- [scuttlebutt](https://scuttlebutt.nz)
- instagram
- facebook
- twitter

Home servers based [LibreCrafts](https://librecrafts.com/) for people who want
NAS,
and non-NAS options with:
- [pine64](https://www.pine64.org)
- [Raspberry Pi](https://www.raspberrypi.org) (discouraged: expensive)

Mobile devices based on [lilygo.cc](https://lilygo.cc/)
