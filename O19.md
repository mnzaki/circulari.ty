# O19 (née October19)

As seen on [github.com/mnzaki/o19](https://github.com/mnzaki/o19)

A monorepo that brings together:
- pnpm + turbo
- Typescript
- Tauri
- SvelteKit
- foundframe
  - PKB management
  - web and media swiss knife
  - p2p connectivity

And code packages for the foundations:
- Identity management
- Content storage
  - by content hash
  - with metadata
  - transparently over physical storage
- Peer management
  - finding peers
  - connecting to peers
