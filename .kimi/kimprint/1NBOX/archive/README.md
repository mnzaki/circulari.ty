# 1NBOX Archive

> *"DONE is created here, never moved here."*

## What's Here

This directory contains:

- **DONE-*.md** - Completed work (created directly here)
- **RESPONSE-*.md** - Consumed responses (moved here by consumer)

## How to Use

### Create DONE

```bash
# Create DONE file DIRECTLY in archive/
cat > 1NBOX/archive/DONE-my-work.md << 'EOF'
---
from: I am working on X
timestamp: 2026-02-23T18:00:00Z
---

# DONE: My Work

...
EOF
```

**Never create DONE in 1NBOX/ and move it.**

### Archive RESPONSE

```bash
# As the CONSUMER, move to archive when done
mv 1NBOX/RESPONSE-to-me.md 1NBOX/archive/RESPONSE-to-me.md
```
