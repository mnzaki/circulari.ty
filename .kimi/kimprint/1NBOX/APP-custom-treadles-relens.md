# APP: Custom Treadles & The Relens Pattern

> *"The same warp, seen through different glass."*

## Goal

Create a custom treadle that generates internal wiring (DbActor bindings) for foundframe, using the new `@loom.relens()` pattern.

## The Concept: Relens

In optics, a **lens** transforms without changing the essence. In the loom:

```typescript
// @loom.relens() - Transform the ring while preserving its nature
@loom.relens(myCustomTreadle)
const foundframe = loom.spiral(FoundframeCore);

// foundframe is still a FoundframeRing, but now with generated internals
// The treadle has added DbActor bindings inside the package
```

**Metaphor:** Like adding a **tie-up** to the loom - the treadle (custom code) is now connected to the harness (ring), but the warp threads (ring type) remain unchanged.

## Why Not "Jumper Wires"?

Too electronic! Instead:
- **Tie-ups** - How treadles connect to harnesses (loom-native)
- **Heddle hooks** - What lifts the warp
- **Shuttle tracks** - Paths through the weave
- **Beater bridges** - What packs the weft

We use **relens** - refocusing the ring through custom generation logic.

## Phase 1: Create Custom Treadle

### Step 1.1: Define the Treadle

**File:** `o19/loom/treadles/dbbindings.ts`

```typescript
/**
 * DbBindingTreadle - Generates DbActor bindings for entities
 * 
 * This treadle examines the core's entities (Bookmark, Media, etc.)
 * and generates SQLite bindings via DbActor.
 */

import type { TreadleContext, TreadleResult } from '@o19/spire-loom/machinery/treadles';
import type { SpiralRing } from '@o19/spire-loom/warp';

export interface DbBindingConfig {
  entities: string[];      // ['Bookmark', 'Media', 'Post']
  operations: ('create' | 'read' | 'update' | 'delete' | 'list')[];
}

export const dbBindingTreadle = defineCustomTreadle({
  name: 'dbbindings',
  
  // The relens pattern: input ring = output ring
  relens: true,
  
  async generate(context: TreadleContext): Promise<TreadleResult> {
    const { ring, managements, config } = context;
    const dbConfig = config as DbBindingConfig;
    
    const generatedFiles: string[] = [];
    
    // Generate DbActor commands for each entity
    for (const entity of dbConfig.entities) {
      // Find the management for this entity
      const mgmt = managements.find(m => m.name === `${entity}Mgmt`);
      if (!mgmt) continue;
      
      // Generate: src/db/entities/{entity}.gen.rs
      const dbEntityCode = generateDbEntity(entity, mgmt, dbConfig.operations);
      const entityPath = `${ring.packagePath}/src/db/entities/${entity.toLowerCase()}.gen.rs`;
      await writeFile(entityPath, dbEntityCode);
      generatedFiles.push(entityPath);
      
      // Generate: src/db/commands/{entity}.rs (DbCommand variants)
      const commandsCode = generateDbCommands(entity, mgmt, dbConfig.operations);
      const commandsPath = `${ring.packagePath}/src/db/commands/${entity.toLowerCase()}.gen.rs`;
      await writeFile(commandsPath, commandsCode);
      generatedFiles.push(commandsPath);
    }
    
    // Update db/mod.rs to include new modules
    await updateDbMod(ring, dbConfig.entities);
    
    return {
      generatedFiles,
      modifiedFiles: [`${ring.packagePath}/src/db/mod.rs`],
    };
  },
});

// Helper: Generate DbActor entity trait
function generateDbEntity(
  entity: string,
  mgmt: ManagementMetadata,
  operations: string[]
): string {
  return `
// GENERATED BY DBBINDING TREADLE - Do not edit
use crate::db::{DbHandle, Result};
use crate::${entity.toLowerCase()}::${entity};

#[async_trait]
pub trait ${entity}Db {
  ${operations.map(op => `
  async fn ${op}_${entity.toLowerCase()}(&self, ...) -> Result<...>;
  `).join('\n')}
}

#[async_trait]
impl ${entity}Db for DbHandle {
  // Implementation calls DbActor with appropriate DbCommand
}
`;
}

// Export for use in WARP.ts
export { dbBindingTreadle };
```

## Phase 2: Use in WARP.ts

### Step 2.1: Apply the Relens

**File:** `o19/loom/WARP.ts`

```typescript
import { dbBindingTreadle } from './treadles/dbbindings.js';

// Foundframe core with DbActor bindings
@loom.relens(dbBindingTreadle, {
  entities: ['Bookmark', 'Media', 'Post', 'Person'],
  operations: ['create', 'read', 'update', 'delete', 'list'],
})
const foundframe = loom.spiral(loom.rustCore());

// The rest of the spiral...
const android = foundframe.android.foregroundService();
const desktop = foundframe.desktop.direct();
const tauri = loom.spiral(android, desktop).tauri.plugin();

// Hybrid frontend (read→drizzle, write→tauri)
const drizzle = tauri.typescript.drizzle_adaptors();
const tauriWrite = tauri.typescript.tauri_adaptors();
const front = loom.hybridAdaptor(drizzle, tauriWrite);
```

## Phase 3: Integration with Existing Flow

### Step 3.1: Event Indexer Uses Generated Code

The `EventIndexer` we built can now use the generated traits:

```rust
// In src/db/indexer.rs
use crate::db::entities::BookmarkDb;  // Generated!

fn handle_event(&self, event: TheStreamEvent) -> Result<()> {
  match event {
    TheStreamEvent::ChunkAdded { chunk, .. } => {
      match chunk.content_type() {
        "Bookmark" => {
          if let Some(db) = &self.db {
            // Use generated trait method
            db.insert_bookmark_from_chunk(chunk).await?;
          }
        }
        // ... other entities
      }
    }
  }
}
```

### Step 3.2: TheStream Methods Use Generated Code

```rust
// In src/bookmark.rs (hand-written, uses generated traits)
impl BookmarkStream for TheStream {
  fn add_bookmark(&self, url, title, notes) -> Result<StreamEntry> {
    // 1. Add to PKB
    let entry = self.add_chunk(directory, path, chunk)?;
    
    // 2. Also update SQLite directly (if db available)
    if let Some(db) = self.db() {
      // Use generated method
      db.insert_bookmark(url, title, notes)?;
    }
    
    Ok(entry)
  }
}
```
