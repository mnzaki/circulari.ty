## Key Finding

The **DbActor I implemented** exists in `foundframe/src/db/actor.rs` and is held by the `Foundframe` struct as `db: Mutex<Option<DbHandle>>`...

**BUT** it's NOT being used yet!

The current flow is:
- Tauri commands → TheStream → PKB (git files)

The DbActor was designed for:
- MediaSourceRegistry → DbHandle → SQLite

## The Disconnect

The spire-loom generates bindings that expect `thestream.add_bookmark()` etc., but:
1. TheStream uses PKB/git, not the DbActor
2. DbActor was built for media sources, not bookmarks
3. The beater is supposed to generate ORM code that bridges this
