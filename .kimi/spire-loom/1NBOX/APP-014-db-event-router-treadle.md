# APP-014: DB Event Router Treadle

**Status:** Proposal  
**Pattern:** Event-driven DB synchronization from TheStream™  
**Target:** Generate event router that maps StreamChunks to DB entities  
**Depends On:** APP-013 (entity field metadata)

---

## The Challenge

TheStream™ emits `TheStreamEvent::ChunkAdded` when content is ingested. We need to:
1. Listen to these events
2. Map `StreamChunk` variants to Entity types
3. Extract data and insert into SQLite via DbActor

**Current State:** `db/indexer.rs` has TODOs where DB calls should happen.

**The Question:** Can we generate this boilerplate with a treadle?

**Answer:** YES! The pattern is completely regular and mappable.

---

```typescript

  // ... existing entity/trait/command generation ...

    {
      template: 'rust/db/event_router.rs.ejs',
      path: 'src/db/event_router.gen.rs',
      language: 'rust'
    }
  ],
  
  patches: [
    // Patch indexer.rs to call event router
    {
      type: 'ensureBlock',
      targetFile: 'src/db/indexer.rs',
      marker: 'event-routing',
      template: 'rust/db/indexer_routing.rs.ejs'
    }
  ]
});
```

### Option B: New DbEventRouterTreadle

Separate treadle for clarity:

```typescript
export const dbEventRouterTreadle = defineTreadle({
  name: 'db-event-router',
  
  data: (ctx) => ({
    // Get entities that can be ingested from StreamChunks
    entities: ctx.entities?.all?.filter(e => e.options?.streamable)
  }),
  
  outputs: [{
    template: 'rust/db/event_router.rs.ejs',
    path: 'src/db/event_router.gen.rs',
    language: 'rust'
  }],
  
  patches: [{
    targetFile: 'src/db/mod.rs',
    marker: 'event-router',
    template: 'rust/db/event_router_mod.rs.ejs'
  }]
});
```

## Template Structure

### event_router.rs.ejs

```rust
// GENERATED BY db-event-router Treadle

use crate::db::{DbHandle, Result};
use crate::db::entities::*;
use crate::pkb::StreamChunk;
use crate::thestream::{StreamEntry, TheStreamEvent};

/// Routes TheStream events to appropriate DB entities.
pub struct DbEventRouter {
    db: DbHandle,
}

impl DbEventRouter {
    pub fn new(db: DbHandle) -> Self {
        Self { db }
    }

    /// Handle a TheStream event.
    pub fn handle_event(&self, event: TheStreamEvent) -> Result<()> {
        match event {
            TheStreamEvent::ChunkAdded { chunk, .. } => {
                self.handle_chunk_added(chunk)?;
            }
            TheStreamEvent::EntryPulled { chunk, .. } => {
                self.handle_chunk_added(chunk)?;
            }
            TheStreamEvent::ChunkUpdated { chunk, .. } => {
                self.handle_chunk_updated(chunk)?;
            }
            TheStreamEvent::ChunkRemoved { entry_id, .. } => {
                self.handle_chunk_removed(entry_id)?;
            }
            _ => {}
        }
        Ok(())
    }
```

## Required Metadata

Entities need to declare their StreamChunk mapping:

```typescript
// In loom/*.ts

@BookmarkMgmt.Entity({
  streamable: {
    // Match StructuredData with db_type="Bookmark"
    chunkType: 'StructuredData',
    matchCondition: 'db_type == "Bookmark"',
    
    // Field mappings from JSON data to Entity fields
    fieldMappings: [
      { source: 'data["url"].as_str()?.to_string()', dest: 'url' },
      { source: 'data["title"].as_str().map(String::from)', dest: 'title' },
      { source: 'data["notes"].as_str().map(String::from)', dest: 'notes' },
      { source: 'data.clone()', dest: 'creationContext' },
    ]
  }
})
class Bookmark {
  id = crud.field.id();
  url = crud.field.string();
  title = crud.field.string({ nullable: true });
  notes = crud.field.text({ nullable: true });
  creationContext = crud.field.json<Record<string, unknown>>();
  createdAt = crud.field.createdAt();
}
```

Or more simply, as an extension to entity metadata:

```typescript
// EntityMetadata extension
interface EntityMetadata {
  // ... existing fields ...
  
  streamMapping?: {
    // Which StreamChunk variant(s) map to this entity
    chunkTypes: ('MediaLink' | 'TextNote' | 'StructuredData')[];
    
    // For StructuredData, which db_type value
    dbType?: string;
    
    // Field extraction code snippets
    fieldExtractors: Record<string, string>;
  };
}

// Example for Bookmark
{
  name: 'Bookmark',
  streamMapping: {
    chunkTypes: ['StructuredData'],
    dbType: 'Bookmark',
    fieldExtractors: {
      url: 'data["url"].as_str()?.to_string()',
      title: 'data["title"].as_str().map(String::from)',
      notes: 'data["notes"].as_str().map(String::from)',
      creationContext: 'data.clone()',
      createdAt: 'chrono::Utc::now().timestamp_millis()'
    }
  }
}
```

## Benefits

1. **Type Safety:** Generated code ensures field mappings are correct
2. **Consistency:** All entities follow same event handling pattern
3. **Maintainability:** Change mapping in one place (loom file)
4. **Extensibility:** Add new entity → automatically gets event routing
5. **Testability:** Generated router can be unit tested independently

## Implementation Phases

### Phase 1: Basic Insert
- Generate event router with `ChunkAdded` handling
- Support simple field mappings (String, i64, JSON)
- Route to `db.insert_*` methods

### Phase 2: Update/Delete
- Add `ChunkUpdated` handling
- Add `ChunkRemoved` handling
- Lookup by content hash or reference

### Phase 3: Relationships
- Handle foreign key lookups (e.g., find MediaSource by URL)
- Support junction table insertions (ConversationParticipant)
- Transaction management across multiple inserts

### Phase 4: Advanced Features
- Batch processing for sync operations
- Conflict resolution strategies
- Event replay/recovery
