# O19? foundframe? what? radicle?

It's very simple really.

`**radicle**` is a git server with builtin PKI based identity system and
following and seeding functionality

`**foundframe**` is the *found*ational *frame*work upon which the apps are built.
It's the set of types and services for: Media, Bookmark, Post, Person,
Conversation
  - `foundframe-front` is for JS frontends
  - `foundframe-tauri` is a tauri plugin

`**o19**` is a monorepo-template, it has packages (typescript) and crates (rust) that let you
develop cross-platform p2p (non-global-blockchain) apps.

`**circulari.ty**` is a company, a #solarpunk software house that both uses and
builds `o19`, aspiring to become    
`**spirali.ty**`, an open source foundation.
